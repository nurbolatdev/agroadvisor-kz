# Brand kit

Logo and app icons of AgroAdvisor KZ. Colors follow the design system: primary `#2D6A3E`, primary dark `#1E4D2B`, wheat `#E3A82B`.

## SVG

| File | Use |
| --- | --- |
| `svg/logo-horizontal.svg` | Main logo on light backgrounds (headers, documents) |
| `svg/logo-horizontal-on-dark.svg` | Main logo on dark or green backgrounds |
| `svg/symbol-color.svg` | Symbol only, color — compact navbar, avatars |
| `svg/symbol-white.svg` | Symbol only, white — on dark backgrounds |
| `svg/symbol-mono-dark.svg` | Symbol only, single dark color — print, watermarks |
| `svg/app-icon.svg` | App icon / favicon source (symbol on dark green) |
| `svg/android-foreground.svg`, `svg/android-background.svg` | Android adaptive icon layers |

## PNG

| File | Use |
| --- | --- |
| `png/logo-horizontal-1200.png`, `png/logo-horizontal-on-dark-1200.png` | Presentations, social media |
| `png/symbol-color-512.png`, `png/symbol-white-512.png` | Raster symbol |
| `png/app-icon-ios-1024.png` | iOS App Store icon |
| `png/app-icon-512.png`, `png/app-icon-192.png` | PWA / Android / web manifest |
| `png/android-foreground-432.png`, `png/android-background-432.png` | Android adaptive icon layers |
| `png/favicon-32.png`, `png/favicon-48.png` | Browser favicons |

## Rules

- Do not recolor, stretch or rotate the logo.
- Keep clear space around the logo of at least the height of the leaf.
- Use the on-dark / white versions on backgrounds darker than `#46564B`.
